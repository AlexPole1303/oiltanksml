# Прогноз недельного изменения запасов в Кушинге

Модель прогнозирует изменение запасов в первой публикации EIA. Единица в исходной панели — миллион баррелей. Оценки ошибки ниже и результат команды прогнозирования выражены в тысячах баррелей.

## Текущая версия

На тех же 148 выпусках с 10 января 2024 года по 4 ноября 2026 года средняя абсолютная ошибка (MAE) снизилась с **284,73 до 247,10 тыс. баррелей**. На исходных 139 неделях, где в прежнем архиве уже был опрос API, ошибка снизилась с **254,52 до 233,67 тыс.** До цели по всему календарю остаётся **47,10 тыс.** Абсолютная ошибка уложилась в 200 тыс. на 71 неделе из 148, прежде таких недель было 66. Верный знак недельного изменения получен в 133 выпусках, прежде в 126. [Все 148 прогнозов](balance_forecasts.csv) · [Метрики, интервалы и диагностика](balance_evaluation.json).

| Выпуски | Число | Прежняя MAE | После обновления архива и переобучения прежней модели | Итоговая MAE |
|---|---:|---:|---:|---:|
| Весь календарь | 148 | 284,73 | 260,59 | **247,10** |
| Опрос уже был у прежней модели | 139 | 254,52 | 247,97 | **233,67** |
| Опроса у прежней модели не было | 9 | 751,28 | 455,46 | **454,59** |
| 2024 год | 51 | 261,92 | 257,93 | 237,36 |
| 2025 год | 53 | 321,40 | 275,13 | 268,96 |
| 2026 год по 4 ноября | 44 | 267,01 | 246,16 | 232,07 |

Все ошибки в таблице выражены в тысячах баррелей. Восстановлены шесть из девяти пропущенных опросов и уточнены 13 прежде известных значений на проверочном календаре. Отдельное дополнение относится к 2022 году. Для каждого нового числа сохранены отчётная неделя, время сообщения, ссылка и хеш текста. Значения сверены со второй публикацией. Если исходный бюллетень последовательно округлял данные до сотен тысяч баррелей, в прогноз попало опубликованное округлённое число. С обновлённым архивом MAE на 145 неделях с опросом составила 233,83 тыс., на трёх оставшихся неделях — 888,68 тыс. [Реестр первичных сообщений и подтверждений](precision_observations.csv).

На 152 выпусках 2021–2023 годов проверены 29 вариантов поправки. Модели учились на результатах, известных до соответствующего прогноза. Выбранная поправка использует накопленную разницу между уже опубликованными изменениями запасов по EIA и по API. На неделях с опросом 90,76% веса получила поправка по этой разнице с постепенным забыванием старых недель. Остальные 9,24% получила модель с оценкой расхождения уровней запасов и дополнительной калибровкой опроса. Коэффициенты этих поправок пересчитывались каждые четыре выпуска. На последовательной проверке 2022 и 2023 годов MAE снизилась на 13,45 тыс. на 90 неделях с опросом. Для прогноза без опроса также проверены изменения загрузки НПЗ, запасов за пределами Кушинга, кривой WTI, местной температуры, спутниковые наблюдения и опубликованные опросы по нефтепродуктам. [Веса модели](balance_weights.json) · [Датированные входные данные](balance_inputs.csv) · [Опросы по нефтепродуктам](product_observations.csv).

На всех 148 выпусках парный 95%-й интервал снижения MAE составил **17,65–58,96 тыс. баррелей**, на исходных 139 неделях с опросом — **8,47–35,23 тыс.** Для расчёта использован круговой блочный бутстрэп с длиной блока четыре выпуска. Этот календарь уже использовался при оценке прежних версий. Даже подбор постоянных неотрицательных весов с суммой один по раскрытым ответам дал в проверенном наборе прогнозов минимум **235,65 тыс.** Эта ретроспективная величина характеризует конкретный набор моделей. При расчёте рабочих прогнозов используются веса, выбранные до 2024 года.

Отдельно проверен открытый спутниковый ряд Cushing Watch. Для 64 недель настройки и 50 недель проверки удалось сопоставить два близких по времени пролёта. Вес спутниковой поправки, выбранный на ранних данных, составил 5,26%. С ним MAE на тех же 148 выпусках выросла до **249,19 тыс.** Издатель пересчитывал архив снимков в 2026 году. Сравнение выполнено отдельно от рабочего прогноза. Его можно повторить командой `python scripts/audit_cushing_satellite_balance.py`. Скрипт проверяет SHA-256 версии публичного графика. [История пересчёта у издателя](https://cushingwatch.com/weeks/2026-09-11) · [Спутниковый ряд](https://cushingwatch.com/analysis).

### Воспроизведение

Обучение и проверка работают на сохранённых в репозитории входах. Сначала можно запустить только раннюю проверку, затем пересчитать весь календарь и построить прогноз на отдельный выпуск.

```sh
python scripts/fit_cushing_survey_balance.py --validation-only
python scripts/fit_cushing_survey_balance.py
python scripts/fit_cushing_survey_balance.py --predict models/cushing_inventory/nov18_inputs.json --as-of 2026-11-18T05:00:00Z
python -m unittest discover -s tests
```

Параметр `--as-of` задаёт момент принятия решения. Если уточнение цифры вышло позже этого времени, модель использует доступную на тот момент версию сообщения. Для следующих выпусков можно передать обновлённые таблицы через `--precision-ledger`, `--balance-inputs`, `--products` и `--settled-feedback`. Единицы и названия столбцов соответствуют сохранённым таблицам. Повторный сбор исходных публикаций выполняют [коллектор опросов по Кушингу](../../scripts/collect_cushing_survey_precision.py) и [коллектор опросов по нефтепродуктам](../../scripts/collect_cushing_product_surveys.py).

## Версия с MAE 284,73 тыс. баррелей

На тех же 148 выпусках с 10 января 2024 года по 4 ноября 2026 года MAE снизилась с **315,50 до 284,73 тыс. баррелей**. До целевого уровня 200 тыс. остаётся 84,73 тыс. В пределах ±200 тыс. оказались 66 из 148 прогнозов, у предыдущей версии таких было 64. Величина ошибки относится к недельному изменению запасов относительно первой публикации EIA. В этом проекте тот же исторический календарь проверяли ранее. [Недельные прогнозы](measurement_forecasts.csv) · [Результаты и интервалы](measurement_evaluation.json).

| С опросом API | 139 | 254,52 | 314,53 | 123 |

В реестр вошли 28 подтверждённых дополнений и исправлений за весь архив. На проверочном периоде восстановлены 5 пропущенных оценок, исправлены ещё 2. Записи Sina Finance сверены по времени публикации и редактирования. Для документов Hicend проверены время создания и изменения PDF и метка сервера. Во всех случаях сверены знак, величина и отчётная неделя с календарём FX168. Общая панель измерений содержит 293 сопоставленных национальных оценок API. [Реестр со ссылками и временем](wire_observations.csv) · [Панель измерений](measurement_inputs.csv).

Проверены 48 конфигураций фильтров и дополнительная сеть 32→16 с тремя инициализациями и 256 эпохами. Фильтры используют расхождения API и EIA за последние недели, региональные запасы, национальный опрос и сезонность. Веса фильтров пересчитываются каждые 13 выпусков, сети обучаются заново перед каждым проверяемым годом. На каждой дате используются уже известные результаты. Для отбора моделей использованы 152 выпуска 2021–2023 годов. Проверка выбрала переобученную на исправленном архиве прежнюю архитектуру. На неделях с опросом 61,8% веса приходится на оценку API с поправкой, обученной на прошлых расхождениях с EIA, 38,2% — на прежний ансамбль. При пропуске используется спутниково-рыночный прогноз. Если только добавить подтверждённые данные и для изменённых недель брать 90% опроса и 10% спутниково-рыночного прогноза, MAE составит 285,22 тыс. Дополнительная сеть обучалась на 403 неделях с опросом, лучшей оказалась эпоха 37. При отборе на ранней истории эта дополнительная сеть получила нулевой вес. [Проверка по эпохам](measurement_epochs.csv) · [Параметры прогноза](measurement_weights.json).

Выигрыш относительно прежней версии составил 30,77 тыс. баррелей. Парный 95%-й интервал по 4 000 круговым блочным выборкам длиной четыре выпуска составил от 9,19 до 61,51 тыс. Если после раскрытия ответов подобрать оптимальные постоянные неотрицательные веса с суммой один отдельно для недель с опросом и без него, минимум среди проверенных прогнозов составит 257,81 тыс. Такой подбор использован только для оценки предела этого набора моделей.

При добавлении ретроспективного радарного индекса получено 283,87 тыс. У Pelyr основная часть истории восстановлена задним числом. Этот эксперимент учитывает даты доступности исходных снимков, а в рабочий прогноз индекс не включён. [Методика, архив и датированные прогнозы Pelyr](https://pelyr.com/research/oil-storage/).

## Версия с MAE 315,50 тыс. баррелей

На 148 выпусках с 10 января 2024 года по 4 ноября 2026 года средняя абсолютная ошибка (MAE) уменьшилась с **445,05 до 315,50 тыс. баррелей**, на 29,1%. Модель верно определила направление изменения запасов в 123 выпусках. Календарь проверяли и в прежних исследованиях проекта. Архитектуры сравнивали и доли компонентов выбирали по более ранним 152 выпускам 2021–2023 годов. Ниже указаны ошибки относительно первой публикации EIA. Восстановлены 24 из 38 ранее пропущенных недель проверочного периода. Оценка API теперь есть для 134 из 148 выпусков. На них MAE составила 275,06 тыс. баррелей. В оставшихся 14 случаях прогноз дал спутниково-рыночный гибрид с MAE 702,55 тыс. На исходной группе из 38 трудных недель ошибка снизилась с 844,42 до 404,04 тыс. Прирост относительно прошлой версии составил 129,56 тыс. баррелей, парный 95%-й интервал блочного бутстрэпа — от 59,38 до 218,08 тыс. По сравнению с той же моделью на расширенном архиве обученная поправка уменьшила MAE ещё на 20,34 тыс., интервал от 11,69 до 29,18 тыс. Это ретроспективное сравнение на знакомом календаре.

Дополнительный реестр содержит 52 датированных сообщения за весь период. Для допуска требуются отчётная неделя API в архиве FX168, совпадающие направление и величина изменения запасов в Кушинге и отдельное сообщение, доступное до отсечки. В 41 случае это статья OilPrice, в 11 — сообщение публичного канала, который автоматически копирует ленту FinancialJuice и указывает, что ведётся независимо от редакции. Для статьи используется время последней правки. Для сообщения проверяются время отправки, точность округления и доступная отметка редактирования. Архив FX168 собран ретроспективно. Исходные ссылки, часы, значения и хеши сохранены для проверки. [Дополнительный реестр](confirmed_observations.csv) · [Пример конкретной недели в FX168](https://www.fx168news.com/calendar/190679) · [Описание канала](https://t.me/s/FinancialJuice).

Новые сети со слоями **32 и 16 нейронов** обучены с тремя инициализациями. Первая прогнозирует расхождение опроса с EIA. Вторая использует только признаки, доступные без текущего опроса, и учится дополнительно оценивать прежние опросы. Для каждого исторического года обучение заканчивается до первой отсечки этого года. Для окончательных весов проверены все 256 эпох, с выбором по последним 39 доступным неделям. Лучшими оказались эпохи 47 и 1 соответственно. На календаре настройки отдельные выходы этих двух сетей получили нулевые веса. При доступном опросе 38,21% прогноза даёт прежний ансамбль с нейросетевыми компонентами и 61,79% — обученная поправка. Она учитывает разницу опроса с гибридным прогнозом и расхождения между опросом и EIA в предыдущие недели. При выборе весов для резервной модели дополнительно проверили все недели настройки со скрытым текущим опросом. ## Откуда берутся данные

Панель содержит 720 недельных обучающих строк. Первые 53 выпуска архива с 2012 года дают предысторию для лагов. В признаках учтены предыдущие первые публикации EIA, изменения запасов в других районах, сезонность, спутниковые измерения и цены WTI и Brent в архивной версии, доступной до прогноза. Публичные сети используют недели со снимками и без них. Повторное обучение на историческом календаре выполняется блоками по 13 выпусков с использованием исходов, известных до начала блока. [Недельная панель](weekly_inputs.csv).

Реестр опроса построен по открытым датированным сообщениям OilPrice о данных API. Коллектор просматривает годовые карты новостей в заданном окне накануне EIA. Он проверяет, что статья ссылается на API, относится к Кушингу и содержит однозначно читаемые направление и величину. Если в первой фразе есть отчётная неделя, коллектор сверяет её с целевой. Для остальных статей привязка опирается на окно публикации очередного опроса. Для допуска используется время последней правки, строго предшествующее отсечке. Открытый реестр неполон. В нём 332 наблюдения, последнее предназначено для отдельной реконструкции ноября. Даты и хеши относятся к версии страницы, полученной при сборе. ## Обучение и выбор весов

На 152 выпусках 2021–2023 годов сравнивались ширины 16, 32→16 и 64→32, по три случайные инициализации. Модель с калибровкой использует два ансамбля 32→16. Один предсказывает изменение запасов по длинной истории, другой учится на прошлых ошибках гибрида. Число эпох выбирается на последних 39 известных наблюдениях каждого обучающего окна. После этого веса заново обучаются на всём доступном окне.

Отдельная сеть с восемью скрытыми нейронами училась выбирать долю опроса. При финальном обучении проверено 59 поколений по 64 особи, лучшая ошибка на блоке ранней остановки достигнута в поколении 27. Для ретроспективной проверки эту сеть обучали перед каждым проверяемым календарным годом. В итоговом ансамбле её отдельный выход получил нулевой вес. Выбранный прогноз использует две поправки от сетей 32→16, оценку API со сдвигом по прежним ошибкам и уменьшенную по амплитуде оценку API.

Для весов итогового ансамбля поиск сравнил **256 поколений по 96 вариантов**. Функция потерь — средняя абсолютная ошибка по всему календарю настройки. Наборы весов для недель с опросом и без него различаются. Затем линейное программирование дало точный минимум в пределах двух заданных наборов прогнозов и неотрицательных весов с суммой один. Он составил **534,165 тыс. баррелей на 152 выпусках настройки**. На новых неделях ошибка может отличаться. [Журнал всех поколений](generations.csv) · [Веса итогового ансамбля](survey_mixture.json).

## Как воспроизвести

Из корня проекта в окружении с установленными зависимостями выполните три команды по порядку. Для обучения достаточно двух CSV в этой папке. Полный архив снимков и страниц требуется при пересборке исходной панели и реестра.

```sh
python scripts/fit_cushing_inventory_network.py
python scripts/fit_cushing_network_calibration.py
python scripts/fit_cushing_survey_ensemble.py
```

Сохранённые веса позволяют проверить расчёт для выпуска 18 ноября без повторного обучения. Команда получает входные признаки без фактического результата. Оценка API допускается, только если её публикация предшествует указанному времени. Для нового реестра предусмотрен аргумент `--survey-ledger`.

```sh
python scripts/fit_cushing_survey_ensemble.py --predict models/cushing_inventory/nov18_inputs.json --as-of 2026-11-18T05:00:00Z
python -m unittest discover -s tests
```

Реконструкция выполнена 25 ноября. Для отсечки 18 ноября в 05:00 UTC она дала −1 306,61 тыс. баррелей. EIA сообщило −1 209 тыс., абсолютная ошибка составила 97,61 тыс. Ранее зарегистрированный гибрид дал −78,83 тыс. баррелей и был рассчитан за несколько дней до публикации API. Для этой реконструкции использованы более свежие входные данные. [Проверка выпуска](nov18_score.json) · [Архивный отчёт EIA, таблица 4](https://www.eia.gov/petroleum/supply/weekly/archive/2026/2026_11_18/wpsr_2026_11_18.php).
